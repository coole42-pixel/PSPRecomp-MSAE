# Touch control skin

Source art for the Android touch overlay. The files in `svg/` are generated by
`tools/android/gen_touch_skin.py`. To change colours or opacity across the whole
skin, edit the palette at the top of that script and regenerate:

```
python tools/android/gen_touch_skin.py
```

Open `preview.html` in a browser to see every asset, plus a layout mock-up over
dusk, desert and mud backgrounds.

## Format

- 256x256 viewBox, transparent canvas, original geometry.
- Two top-level groups per file: `<g id="background" opacity="1">` (glass body,
  rim, halo) and `<g id="symbol" opacity="1">` (glyph and its glow). Change
  either `opacity` to fade that layer.
- Only paths, basic shapes, linear/radial gradients and group transforms are
  used. There are no filters, masks, clip paths or `<text>` elements, so the
  files rasterize correctly with nanosvg, librsvg or a VectorDrawable converter.
  Glows are built from stacked strokes and gradients, not blur.
- Gradient ids are prefixed per file, so several SVGs can be inlined into one
  document without clashing.

## Assets

| Control | Files |
|---|---|
| Face buttons | `btn_{triangle,circle,cross,square}_{idle,pressed}` |
| Shoulders | `btn_{l,r}_{idle,pressed}` |
| Start / Select | `btn_{start,select}_{idle,pressed}` |
| Legacy pause / menu art (unused by the overlay) | `btn_{pause,menu}_{idle,pressed}` |
| Analog stick | `stick_ring_{idle,pressed}` (base), `stick_cap_{idle,pressed}` (thumb) |
| D-pad | `dpad_idle`, `dpad_{up,down,left,right}_pressed` |

Pressed variants scale the body to about 95.5% around the center and add an
accent glow, so swapping idle for pressed at the same rectangle reads as a press.
The stick cap is drawn to fill its own canvas; draw it at roughly 45-50% of the
ring's size and offset it by the stick deflection. The `_pressed` ring is the
active state while a finger is on the stick.

The D-pad is one sprite with one lit arm per pressed variant. Diagonals would
need composited per-arm overlays, which the generator can be extended to emit.
